IOPROBE - PC-9821 real-machine I/O wait-state probe (tools/hwprobe/ioprobe.s)
Each row: TM_N=1024 back-to-back accesses in a cli window, timed with the PIT
channel-0 counter and an interleaved control (pit-/base-), with the ARTIC counter
(artic-/bartic-) as the cross-check. pit/base are RAW counts (1 count = 406.9 ns,
8 per ARTIC tick, r13/215) and artic/bartic are ticks (1 = 3255.2 ns), so both
give absolute ns with no run-local scale. clk_sys = 30 * (pit-base) / (WAIT5F
pit-base), where 0x005F is the documented 600 ns / 30 clk_sys I/O-wait port, so
the value is the ratio the core's pc9821_iobus.sv io_access_cycles should carry
for the port.
Reads are the safe direction; the write rows write the constant 0x00 (the EGC/
GRCG/mode off state, the -86 register 0, and the PIT latch command at 0x0077).
Sections are BEGIN:IO<port><mode>/END:IO<port><mode>: a hang leaves a BEGIN: with
no END:, and the capture before it is still valid.

IDELAT - PC-9821 real-machine IDE READ latency probe (tools/hwprobe/idelat.s)
Measures command issue -> first DRQ, per-sector PIO transfer, single- vs
multi-sector READ SECTORS, word throughput and the status-poll cost shape.
READ-ONLY on disk: the only ATA commands are IDENTIFY 0xEC and READ SECTORS
0x20 on cylinder 0 / head 0 / sectors 1..S (one track). Time bases are the
device counters: PIT 2457600 counts/s (406.9 ns) and ARTIC 307200 Hz (3255.2
ns); the two must agree at 8 raw PIT counts per ARTIC tick (r13/215).
Sections are BEGIN:/END: bracketed: a hang leaves a BEGIN: with no END:.
BEGIN:SETUP
  BANK 0432 as found = 00
  PITCAL swap=00
  PITPAIR 87 5D
  PITPAIR 8B 57
  PITPAIR B1 51
  PITPAIR D8 4B
  PITPAIR 88 45
  PITPAIR AB 3F
  PITPAIR D4 39
  PITPAIR F4 33
  PITDIV (diagnostic only) coherent max=FFFF accepted=0B07/0B07
  IDENTIFY 0xEC st0 st1 = 50 50 polls=000004DD
  GEO w1 w3 w6 w49 w60 w61 = 1E8A 0010 003F 0B00 3F60 0078
  RANGE cyl=0000 head=00 nsec=8 spt=63
  RATES pit_hz=2457600 artic_hz=307200 (r13/215 8:1, r13/219, raster-checked)
END:SETUP

  0432 was 00 -> now 00
  writes made by this probe: 0432 bank (restored above), task-file setup
  0644/0646/0648/064A/064C, 064E commands 0xEC IDENTIFY and 0x20 READ SECTORS
  only, 0077<-00 (the PIT counter-latch command, stateless), 005F (the
  documented write-only I/O delay port, written 1024 times by CAL WAIT5F),
  and 000A (the slave IMR: saved at each command window and restored from
  the save). No disk data was written: READ SECTORS is read-only and the
  scratch range is cylinder 0 / head 0 / sectors 1..S - one track while
  IDENTIFY word 6 is honest and >= 4; a lying/absent IDENTIFY can make a
  read cross a track boundary (still read-only, the timing may include a
  reposition).

GFXBENC2: per-subsystem real-machine graphics benchmark (Xe10). Each case is a
  cli-timed body around the ARTIC counter. ANCHOR: ARTIC 005C/005F = 307200 Hz (the
  documented free-running tick; egcport.s measures it 0 per-mille off). CLK50 = ARTIC
  ticks * 50000000 / 307200 = ticks * 162.7604, i.e. clk_sys at the core's 50 MHz.
  PER = CLK50 * 1000 / UNITS = MILLI-clk_sys per unit (1952 clk_sys/sprite = 1952000).
  The text-TRAM section scribbles the visible console: redirect stdout to a file.
  The GVRAM is scribbled by design; the EGC/GRCG end off and 0xA6 ends at 0. Disk: untouched.
